# Library Management System

This project is a Library Management System built using DBMS, MySQL, XAMPP - Apache server, and PHP.

## Features

- User authentication (login and registration)
- Add, update, delete, and search for books
- Issue and return books
- Manage user accounts
- View issued book history

## Requirements

- XAMPP (Apache, MySQL, PHP)
- Web browser

## Installation

1. Download and install [XAMPP](https://www.apachefriends.org/index.html).
2. Clone this repository to your local machine:
    ```bash
    git clone https://github.com/devinxhacker/LibraryManagement.git
    ```
3. Copy the project folder to the `htdocs` directory in your XAMPP installation directory.
4. Start the Apache and MySQL services from the XAMPP control panel.
5. Open your web browser and navigate to `http://localhost/phpmyadmin`.
6. Create a new database named `library_management`.
7. Import the `library_management.sql` file located in the `database` folder of the project into the newly created database.
8. Open your web browser and navigate to `http://localhost/LibraryManagement`.

## Usage

1. Register a new user account or log in with an existing account.
2. Use the navigation menu to manage books, issue/return books, and view issued book history.
3. Add, update, delete, and search for books.
4. Issue and return books.
5. Manage user accounts.
